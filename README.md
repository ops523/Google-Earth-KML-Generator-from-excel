# 📍 Excel to KML Geocoder (Streamlit App)

Convert Excel address data into map-ready KML using Google Maps API.

## 🚀 Features
- Upload Excel file
- Geocode addresses
- Generate KML
- Download instantly

## 📂 Expected Columns
- Address
- City (optional)

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
